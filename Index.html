Error y Propagación

Un lado de un cuadrado se mide con instrumento; lo comparamos contra el valor de referencia y propagamos el error hacia el área, A = x².

Cómo se calcula

Toda medición tiene un error respecto al valor real o de referencia. Ese error no se queda quieto: si la medición entra en una fórmula (acá, el área de un cuadrado), el error se "propaga" y afecta al resultado final. La propagación se estima con la derivada de la función respecto a la variable medida — mientras más sensible es la fórmula a un cambio en x, más se amplifica el error.

Error absolutoE_a = | x_v − x_a |
Error relativoE_r = E_a / x_v
Función a evaluarA(x) = x²
Derivada de la funciónA'(x) = dA/dx = 2x
Error propagado (regla de propagación de errores)ΔA = | A'(x_v) | · E_a
Error relativo del áreaE_r(A) = ΔA / A_real

Taylor y Lagrange

Aproximamos e˟ con polinomios de Taylor de grado 1 y 2 alrededor de 0, y acotamos el error con el residuo de Lagrange.

Cómo se calcula

El polinomio de Taylor aproxima una función complicada (como e˟) usando solo sus derivadas en un punto — acá, alrededor de x = 0 (serie de Maclaurin). Cuantos más términos se suman, mejor es la aproximación, pero siempre queda un resto sin calcular. El residuo de Lagrange da una cota: el error máximo que se puede llegar a cometer al cortar la serie en un grado determinado.

Polinomio de grado 1 (P1)P1(x) = 1 + x
Polinomio de grado 2 (P2)P2(x) = 1 + x + x²/2
Error absoluto de cada aproximaciónE_a = | e^x − P_n(x) |
Error relativoE_r = E_a / e^x
Residuo de Lagrange para P2 (cota de error)R2(x) = (e^x / 3!) · x³

Péndulo — Síntesis

De T = 2π√(L/g) despejamos g, propagamos la incertidumbre de L y T, y linealizamos g(T) con Taylor alrededor de un centro a.

Cómo se calcula

Este ejercicio combina todo lo anterior. Partimos del período de un péndulo simple, T = 2π√(L/g), y despejamos g en función de L y T para obtener un valor "experimental". Como L y T se miden con incertidumbre, esa incertidumbre se propaga a g usando las derivadas parciales de g respecto a cada variable — el mismo principio del Ejercicio 1, pero ahora con dos variables en juego. Por último, se linealiza g como función de T con un polinomio de Taylor de grado 1 alrededor de un centro a, para estimar g sin recalcular la fórmula completa.

Período del péndulo (fórmula original)T = 2π · √(L / g)
g despejada (g experimental)g = 4π²L / T²
Error absoluto y relativo de gE_a = |g_real − g_exp| · E_r = E_a / g_real
Derivada parcial respecto a L∂g/∂L = 4π² / T²
Derivada parcial respecto a T∂g/∂T = −8π²L / T³
Incertidumbre total propagada (suma de errores parciales)Δg = |∂g/∂L|·ΔL + |∂g/∂T|·ΔT
Taylor de grado 1 de g(T), centrado en ag(T) ≈ g(a) + g'(a) · (T − a)
